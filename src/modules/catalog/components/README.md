# Componentes del catálogo

Cada sección recibe datos y callbacks desde la composición de la tienda. Estos componentes presentan categorías, productos destacados y promociones; no son propietarios del carrito ni cargan datos por su cuenta.

Los botones notifican selección de categoría o intención de agregar un artículo. La composición conecta esas acciones con el catálogo y el módulo de carrito.
